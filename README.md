## 卡牌收藏 Card Collection

通过 [Weserv](https://wsrv.nl/) 从官网获取卡图以避免跨域问题

点击缩略卡牌查看详情，下载图片或复制链接

切换卡图和文本语言，回溯一年内的游戏版本

老兵与衍生卡独立作为卡池，跟随上级扩展包


Fetch card images via [Weserv](https://wsrv.nl/) to avoid CORS

Click thumbnail to view details, download or copy link

Switch image/text language, browse versions within one year

Veteran and Spawn cards are independent pools, tied to their parent sets

## 卡组构筑 Deck Builder

手动组建或通过卡组代码/二维码导入卡组

生成卡组图片，可添加附件、设置版本、标记卡牌

上传自定义卡牌，或使用相同 `cardId` 替换卡图


Build manually or import via deck code / QR

Generate deck image with attachments, version, and card marking

Upload custom cards, or replace card art using same `cardId`

## 英文直检 Direct Search

无需维护卡牌 JSON 数据，根据英文名转换 cardId

探针检测自动发现同名变体、老兵形态

查找官方未收录卡牌，如**总部**、**旧版抵抗**(于 v53 被移除)、**天气**


No JSON maintenance needed, convert English name to cardId

Probe automatically discovers variants and Veteran forms

Find unlisted cards like **HQ**, **old Resistance**(removed in v53), **Weather**

## 击剑大厅 Duel Hall

填写信息并发布击剑申请

设置等级和卡组 Ban 位

根据预期卡组筛选申请


Post duel requests with details

Set rank and deck ban slots

Filter applications by expected decks
