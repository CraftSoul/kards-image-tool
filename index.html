ℹ️ 搜索语法说明 ▶
_ 匹配任意一个字符　* 匹配任意多个字符
>x 以 x 开头　x< 以 x 结尾　>x< 同时作用
title:xxx 仅搜索卡名　text:xxx 仅搜索卡牌文本
% 分隔多个条件（“且”关系）
示例：title:号<%牌
快捷填充（在搜索框输入后从下拉选择）：
· 白板 / wb → 文本为空的卡
· 非白板 / nwb → 文本非空的卡
· abc（三位数字）→ 花费 a，b 攻 c 防的单位
· abcd（四位数字）→ 花费 a、行动 b、c 攻 d 防的单位
· a/b → a 攻 b 防的单位
注意事项：
·搜索不忽略 空格
·可能匹配不同语言，默认展示中文
